# E&P Systems - AI Agency Website

## What This Is

A bilingual (BG-first / EN) marketing site for E&P Systems, an **AI agency** serving the Bulgarian market. Built with React 19, TypeScript, Tailwind CSS, and Framer Motion in a bold Brutalist style. Multi-page architecture covering 5 AI service pillars (AI websites, automation, agents, SEO, e-commerce), 3 industry verticals (insurance, e-commerce, fitness), an MDX blog engine, and a full SEO/GEO + analytics layer. Default language is Bulgarian; English is the secondary locale.

## Core Value

The site must present E&P Systems as a credible, results-driven AI agency that Bulgarian businesses trust enough to reach out to — and must be discoverable by both search engines and AI answer engines.
