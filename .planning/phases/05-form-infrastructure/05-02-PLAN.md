  <action>
Create `ContactModal.tsx` (~130 lines) that renders the full form inside a portal.

**Structure:**
- Import `createPortal` from react-dom, `useContactModal` from hooks, `useContactForm` from hooks, `useTranslation` from react-i18next, `X` icon from lucide-react, `useEffect` from react
- Get `{ isOpen, context, closeContactForm }` from `useContactModal()`
- Get `{ fields, errors, status, updateField, handleSubmit, reset }` from `useContactForm(context)`
- On close: call `reset()` then `closeContactForm()`

**Scroll lock and Escape key (useEffect):**
- When `isOpen` is true: set `document.body.style.overflow = 'hidden'`, add keydown listener for Escape
- Cleanup: restore `document.body.style.overflow = ''`, remove listener
- Dependency array: `[isOpen, closeContactForm]` (use the close handler that also resets)

**Rendering (only when isOpen is true):**
Use `createPortal(...)` to `document.body`.

Outer container: `fixed inset-0 z-[100] flex items-center justify-center p-4`

Backdrop: `absolute inset-0 bg-black/60` with onClick calling the close handler

Modal card: `relative bg-white border-4 border-black rounded-[30px] p-8 lg:p-10 w-full max-w-lg max-h-[90vh] overflow-y-auto` with class `brutalist-shadow` if it exists in the project (check Tailwind config), otherwise use inline `shadow-[8px_8px_0_0_#000]`

**Close button** (top-right): lucide-react `X` icon, `absolute top-4 right-4`, onClick close handler

**Heading:** Use context to determine heading text:
- If `context?.subject === 'general'` or no context: `t('contactForm.heading.general')`
- Otherwise: `t('contactForm.heading.service', { service: t('contactForm.services.' + context.subject) })`
- Style: `text-2xl lg:text-3xl font-black mb-6`

**Form** (with `noValidate` and `onSubmit` that calls `e.preventDefault()` then `handleSubmit()`):

Four visible fields in order:
1. **Name** (required): `<input type="text">` with label `t('contactForm.fields.name.label')`, placeholder from i18n, value from `fields.name`, onChange calls `updateField('name', e.target.value)`. Show `errors.name` below in red if non-empty. Input styling: `w-full border-2 border-black rounded-xl px-4 py-3 text-base focus:outline-none focus:ring-2 focus:ring-[#B9FF66] focus:border-[#B9FF66]`. Error border: add `border-red-500` when error exists.
2. **Email** (required): Same pattern as Name but type="email", uses `fields.email`, `errors.email`, `contactForm.fields.email.*`
3. **Phone** (optional): Same input pattern, no error state, type="tel", uses `contactForm.fields.phone.*`
4. **Notes** (optional): `<textarea>` with 4 rows, same styling as inputs, uses `contactForm.fields.notes.*`

Labels: `block text-sm font-bold mb-1` for each field. Each field group wrapped in a `<div className="mb-4">`.

**Hidden honeypot field:** Add `<input type="checkbox" name="botcheck" className="hidden" style={{ display: 'none' }} tabIndex={-1} autoComplete="off" />` -- this is the Web3Forms honeypot pattern.

**Submit button:**
- `w-full bg-[#B9FF66] border-4 border-black rounded-xl py-3 font-black text-lg hover:bg-[#a8e65c] transition-colors disabled:opacity-50 disabled:cursor-not-allowed`
- Disabled when `status === 'submitting'`
- Text: `status === 'submitting' ? t('contactForm.submitting') : t('contactForm.submit')`

**Status states:**
- When `status === 'success'`: Replace entire form with success view -- heading `t('contactForm.success.heading')` in green, description, and Close button
- When `status === 'error'`: Show error banner above submit button with `t('contactForm.error.heading')`, `t('contactForm.error.description')`, and a Retry button that calls `handleSubmit()` again

Return `null` when `!isOpen`.
