**ContactModalProvider.tsx** (~35 lines):
- Define `FormContext` interface: `{ subject: string; source: string }` -- subject values are "general", "seo", "ecommerce", "ai", "software"; source values like "hero", "navbar", "service-seo", etc.
- Define `ContactModalContextType` interface: `{ isOpen: boolean; context: FormContext | null; openContactForm: (ctx: FormContext) => void; closeContactForm: () => void }`
- Create the React Context with `createContext<ContactModalContextType | null>(null)`
- Export `ContactModalProvider` component that uses `useState` for `isOpen` (boolean) and `context` (FormContext | null)
- `openContactForm` sets context and isOpen=true (wrap in useCallback)
- `closeContactForm` sets isOpen=false and context=null (wrap in useCallback)
- Renders `<ContactModalContext.Provider value={...}>{children}</ContactModalContext.Provider>` -- do NOT render ContactModal here yet (that comes in Phase 6 Plan 01)
- Export the `ContactModalContext` so useContactModal can import it

**useContactModal.ts** (~8 lines):
- Import `ContactModalContext` from ContactModalProvider
- Return `useContext(ContactModalContext)` with an error guard: if context is null, throw `"useContactModal must be used within ContactModalProvider"`
- Export the hook

**useContactForm.ts** (~80 lines):
- Accept parameter: `formContext: FormContext | null`
- Field state via useState: `fields: { name: string; email: string; phone: string; notes: string }` initialized empty
- Error state via useState: `errors: { name: string; email: string }` initialized empty
- Status state via useState: `'idle' | 'submitting' | 'success' | 'error'`
- `useTranslation()` from react-i18next for translated validation messages
- `updateField(field, value)` function that updates fields and clears the error for that field
- `validate()` function:
  - If name is empty/whitespace: set `errors.name = t('contactForm.validation.nameRequired')`
  - If email is empty/whitespace: set `errors.email = t('contactForm.validation.emailRequired')`
  - Else if email fails regex `/^[^\s@]+@[^\s@]+\.[^\s@]+$/`: set `errors.email = t('contactForm.validation.emailInvalid')`
  - Return true if no errors, false otherwise
- `handleSubmit()` async function:
  - Call validate(), return early if invalid
  - Set status to 'submitting'
  - POST to `https://api.web3forms.com/submit` with JSON body:
    ```
    {
      access_key: import.meta.env.VITE_WEB3FORMS_KEY,
      name: fields.name,
      email: fields.email,
      phone: fields.phone || undefined,
      message: fields.notes,
      subject: formContext?.subject === 'general' ? 'General Inquiry' : `${formContext?.subject} Inquiry`,
      from_name: 'E&P Systems Website',
      botcheck: false
    }
    ```
  - On success (response.ok and data.success): set status to 'success'
  - On failure: set status to 'error'
  - Wrap in try/catch, catch sets status to 'error'
- `reset()` function: reset fields, errors, and status to initial state
- Return: `{ fields, errors, status, updateField, handleSubmit, reset }`
