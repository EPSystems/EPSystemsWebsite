       - Current language visually distinguished: active lang in bold black (or white depending on context), inactive in zinc-400
       - On click: replace the lang segment in current pathname, navigate to new path
       - Use `navigate(newPath, { replace: true })` so language switch doesn't add to browser history
       - Styling: `flex items-center gap-1 font-bold text-lg` - Brutalist aesthetic, minimal

       - Compare old and new pathname: if ONLY the lang prefix changed (e.g., /en/foo -> /bg/foo), do NOT scroll to top
       - Logic: strip leading /en/ or /bg/ from both old and new paths; if the remainder is the same, skip scroll
       - This prevents the language switcher from jumping the user to the top of the page (Pitfall 2 from research)

    3. Update `src/pages/HomePage.tsx`:
       - Import and call useLanguageSync() at the top of the component

       - Keep the Link to homepage using lang param
