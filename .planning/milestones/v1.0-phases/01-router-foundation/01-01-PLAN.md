   - Show "404 - Page Not Found" with a link back to homepage using `Link` from react-router-dom
   - Link goes to `/${lang}/` where lang comes from URL params, falling back to "en"
   - Style consistent with the site (brutalist: bold text, border, rounded corners)

5. Update `src/main.tsx`:
   - Wrap App in `BrowserRouter` from react-router-dom
   - Keep React.StrictMode

6. Rewrite `src/App.tsx` as the route configuration:

   - Import ScrollToTop, HomePage, NotFoundPage
   - Render ScrollToTop component (outside Routes, inside router)
   - Route structure:
     - `path="/"` -> `<Navigate to="/en/" replace />` (per user decision: default to English; browser language detection is unnecessary complexity for a bilingual site)

     - `path="*"` -> `<NotFoundPage />` (catch-all 404)
   - Do NOT add /:lang/services/:slug routes yet -- those are Phase 4 (service pages)
   - The `:lang` param is not validated in this phase (i18n validation comes in Phase 2). Any value works for now.
